# Измерительный комплекс на базе STM32 (Дипломный проект)

Прошивка аппаратно-программного комплекса для сбора, первичной фильтрации и локального логирования телеметрии при проведении опыта кренования. 

Проект реализован на микроконтроллере семейства STM32 и отвечает за строгий тайминг опроса датчиков, взаимодействие с периферийными модулями и вывод телеметрии в реальном времени.

## Стек и технологии
* **Платформа:** STM32 (архитектура ARM Cortex-M)
* **Язык разработки:** C/C++
* **Файловая система:** FatFs (для работы с внешними накопителями)

## Архитектура и реализованный функционал

* **Опрос датчиков (Modbus):** Реализация стабильного обмена данными с инклинометрами по протоколу Modbus (RTU/ASCII). Включает контроль целостности пакетов и проверку контрольных сумм для отсеивания битых данных.
* **Цифровая фильтрация:** Программная обработка сырых значений углов крена непосредственно на микроконтроллере. Реализованы алгоритмы сглаживания для подавления высокочастотного шума и вибраций корпуса судна до момента сохранения данных.
* **Модуль реального времени (RTC):** Взаимодействие с аппаратными часами (по I2C/SPI) для точного таймстемпинга. Каждая запись в массиве данных получает жесткую привязку к реальному времени для синхронизации графиков.
* **Локальное логирование (SD-карта):** Инициализация и потоковая запись отфильтрованных массивов данных на SD-карту (через интерфейс SPI/SDIO). Формирование файлов, готовых для загрузки в Python-обработчик.
* **HMI и визуализация (Дисплей):** Вывод текущих значений крена, статуса SD-карты, текущего времени и состояния системы на внешний экран по шине I2C/SPI для визуального контроля процесса оператором в полевых условиях.
